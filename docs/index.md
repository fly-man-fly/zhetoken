# 注册 & API/Key & 充值

## 注册账号

访问官网：[code.b886.top](https://code.b886.top)

当前支持：LinuxDo 快捷登录 与 邮箱注册

开放注册邮箱：`edu.cn` `gmail.com` `163.com` `126.com` `qq.com`

1. 点击注册
2. 选择需要的注册方式
3. 输入对应信息完成注册

---

## API/URL 与 Key/令牌

### API/URL

登录后右侧 **API信息** 板块即可查看最新的地址

- **Claude** 复制即可
- **Codex** 复制后需添加 `/v1`

### Key/令牌

1. 登录后，左侧 **令牌管理**
2. 点击 **添加令牌**
3. 输入令牌名称并选择对应分组

!!! warning "重要"
    **百分之90的不可用错误都是因为此问题：务必选择分组后提交创建**

4. 推荐保持默认设置即可，点击 **提交**
5. 点击 **密钥** 栏下的复制按钮即复制添加的令牌

---

## 充值与续费

可输入自定义充值数量（1元起），或选择预设充值额度，选择可用支付方式即可。

!!! warning "注意"
    为避免充值不到账情况，付款后务必等待界面提示支付成功后关闭窗口。

**如遇充值未到账，联系站长解决即可**
