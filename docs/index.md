# AI 中转站配置教程

欢迎来到 AI 中转站配置教程中心！本站提供各类 AI 编程工具的中转站配置指南，帮助你快速完成设置，开始使用。

## 快速开始

根据你使用的工具，选择对应的教程：

| 工具 | 类型 | 适合人群 |
|------|------|----------|
| [Codex CLI](codex-cli.md) | 命令行工具 | 开发者，追求最佳性能 |
| [Cline](cline.md) | VS Code 插件 | 日常开发，喜欢在编辑器中操作 |
| [Claude Code](claude-code.md) | 命令行工具 | 开发者，需要 Claude 模型 |

## 获取 API Key

所有工具都需要一个 API Key 才能使用。请先完成以下步骤：

1. 访问控制台：[https://codex-for.me/dashboard.html](https://codex-for.me/dashboard.html)
2. 登录后，在 **API Key 管理** 区域复制你的密钥
3. 如需充值，在「卡密兑换」面板输入卡号即可

!!! tip "提示"
    API Key 是通用的，一个 Key 可以在所有工具中使用。
